## Overview

The **HeartBreak Motivational Quotes App** presents a selection of motivational quotes in an easy-to-use, interactive carousel. The app provides daily inspiration to users through a collection of curated quotes, dynamically loaded from a JSON file. Each quote is displayed in a Bootstrap card within a responsive carousel interface.

## Features

- **Responsive Design**: Optimized for both mobile and desktop views.
- **Interactive Carousel**: Navigate through quotes with simple forward and backward buttons.
- **Dynamic Content**: Quotes are loaded dynamically from a `quotes.json` file, allowing for easy updates.
- **Easy Navigation**: Forward and backward buttons to navigate through different quotes.
- **Footer with Social Media Links**: Links to Twitter and GitHub profiles for engagement.
